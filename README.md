# Run and deploy the App

This contains everything you need to run your app locally.



## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Create a `.env` file in the root directory and add your environment variables. You can use the `.env.example` file as a reference.
3. Run the app:
   `npm run dev`
