Design principles for component design
Principle	What it means in Ekowork
Reusability	One DataTable should support multiple academic records.
Composition	Build complex interfaces using smaller components.
Separation of concerns	Styling, business logic and data retrieval should not be unnecessarily mixed.
Configurability	Components should accept props that determine their behavior.
Role-based rendering	Navigation and available actions should depend on permissions.
Responsive design	Components should work on desktop, tablet and mobile.
Accessibility	Support keyboard navigation, labels and screen readers.
State management	Keep track of active tabs, filters, pagination and modal states.
Type safety	Use TypeScript interfaces and types for component properties.
Consistency	Reuse Ekowork design tokens rather than introducing arbitrary styles.
